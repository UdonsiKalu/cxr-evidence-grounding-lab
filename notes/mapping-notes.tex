\section{What we set out to achieve}

\textbf{Later thesis (not closeable as v1):} automatically change and correct every failure mode in a large language model.

\textbf{This-pass question} (design: \texttt{docs/TRACKB-FAILURE-INTERVENTION-MAP.md}):

\begin{quote}
Can recurring Dual-shaped clinical-note failure signatures be mapped to correction methods that repair those failures while preserving unaffected notes, and could that mapping later support intervention selection?
\end{quote}

Predicate: \texttt{FIRST\_LINE\_THERAPY\_FAILED} on synthetic notes. Neural side fills an extract. Symbolic side: \texttt{ground()} then \texttt{evaluate\_rule()}.

\section{Method}

\begin{itemize}
  \item Dual analog extracts, Goal~2 fill ($n=108$): schema in system, user$=$evidence. Frozen JSON reused; do not overwrite.
  \item Interventions are nested extract relabels in \texttt{n2s\_lab/n2s\_phase2\_translate.py}. Deeper includes earlier.
  \item Score with unchanged \texttt{ground()} and \texttt{evaluate\_rule()}.
  \item Controls: P-neg, P-xspan, P-bind; held-out Dual-wrong scored, not used to invent leftover IDs.
  \item Encode editor: none. Compute editor: CLOSED. No CAA, no frozen-\texttt{d} $\alpha$-chase.
\end{itemize}
