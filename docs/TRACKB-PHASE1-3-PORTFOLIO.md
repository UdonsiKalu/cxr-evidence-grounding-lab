## 1. Summary (one page)

Three surfaces of a CXR Dual-shaped miss, treated as **distinct**:

| Surface | Meaning | Probe | Editor? |
|---------|---------|-------|---------|
| **Encode** | note → neural | L8 class-correct on frozen `d` | **none** (detect only) |
| **Compute** | neural → neural | lost-steps on layer trace | **CLOSED** (frozen-`d` L12+L16+L20 α=2 PARTIAL) |
| **Translate** | neural → symbolic | Dual analog / Dual_full snapshot | **boundary only** (quote-failure promote on FOLFOX Schema extract) |

| Phase | What we did | Outcome |
|-------|-------------|---------|
| **1 Locate** | `:8260` routes known notes using frozen probes | CONTRA → compute · FOLFOX / BC_E1 → translate · T1 incomplete. Routing, **not** causal origin. Response = REVIEW / ABSTAIN contain |
| **2 Forward** | Same Translate intervention on Dual-matched pair | FOLFOX Schema Dual NOT_SATISFIED → **SATISFIED**. Analog CONTRA Dual **CONTRADICTION** no-op. Frozen 2 lost **unchanged** |
| **2 Reverse** | Existing Compute tools vs FOLFOX Dual miss | G5 does not fire on FOLFOX. Frozen-`d` FOLFOX Dual still NOT_SATISFIED. Translate does not clear CONTRA loss |
| **3 Matrix** | 7 locator cases × three surfaces | 3 located · 4 incomplete · **1** boundary Translate repair |

**Conclusion:** a translation-side Dual miss can be repaired at the extract→ground boundary **without** patching hidden states. Existing Compute tools do **not** reproduce that repair. Routing is correlational glue, not a proof that the locator chose the right repair class.

## 3. Plain English (portfolio line)

> I built a three-surface diagnostic for CXR Dual misses — encode, compute, and translate — then tested whether a translation-side fix would stay on the translate-routed note and leave a compute-routed control alone. Promoting failure text the model had already extracted repaired the FOLFOX analog Dual without touching hidden states. Existing inside-net tools did not repair that miss, and did not clear the contradiction note’s layer-loss. Routing is a workbench, not a causal localizer, and REVIEW remains containment rather than repair.

Shorter variant:

> A Dual analog miss on a temporal FOLFOX note was corrected at the extract boundary; the same intervention left a true-contradiction Dual control and its n2n loss untouched — so locate ≠ repair, and we still do not have encode or compute editors.
